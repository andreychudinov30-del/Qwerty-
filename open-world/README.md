# Обратная сторона города — open-world (браузер)

Готовая игра — один файл `../ObratnayaStoronaGoroda.html` (≈14 МБ, всё встроено: код, PBR-текстуры, модели, физика). Открывается двойным щелчком в Chrome / Edge / Safari / Firefox, без сервера и интернета.

Сборка из исходников: `npm install` в корне репозитория, затем `cd open-world && MIN=1 node build.mjs`.

| Модуль | Что делает |
|---|---|
| `src/world/*` | процедурный мегаполис 2.6×2.6 км: районы, дороги с разметкой в шейдере, здания с interior-mapping окнами, деревья, трава, пропсы, небо, погода |
| `src/entities/*` | машины (лофт кузова, физика Rapier, деформация), люди (скелетная модель, одежда, лица, рэгдолл) |
| `src/ai/*` | трафик со светофорами, пешеходы с характером и памятью, полиция 1–5★, ИИ-водители |
| `src/game/*` | игрок, камера, оружие, 25 миссий (`story.js`), экономика и интерьеры |
| `src/ui/*` | HUD, миникарта (реальный рендер города сверху), карта с GPS, меню и настройки |

Текстуры и пропсы: Poly Haven (CC0). Персонаж: пример three.js (Mixamo-риг).
