# METRO HORROR: Последний поезд

Атмосферный сюжетный 3D-хоррор для браузера (ПК, Android, iPhone): 4 главы, 32 миссии, монстры с ИИ, кооператив на двоих через Supabase Realtime, друзья, скины, гибкие настройки графики и редактор сенсорных кнопок.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # готовая сборка в dist/
npm run preview    # проверить сборку
```

Готовая сборка (`dist/`) — статические файлы; их можно выложить на любой хостинг (Vercel, Netlify, GitHub Pages, nginx). Игре нужен HTTPS (или localhost) для pointer lock, аудио и service worker.

Параметры URL для отладки: `?mission=c2m4&unlock=1` — сразу запустить миссию, `?join=123456` — подключиться к комнате, `?q=low` — пресет графики (только для dev.html).

## Управление

ПК: WASD — движение, Shift — бег, Ctrl/C — присесть, Пробел — перелезть через препятствие, E/ЛКМ — действие (удерживать для долгих), F/ПКМ — фонарь, R — сменить батарейку, H — аптечка, Q — бросить бутылку (отвлечь монстров), G — фальшфейер, Esc — пауза.

Смартфон: плавающий джойстик слева, обзор — правая половина экрана, кнопки (бег, присед, действие, фонарь, лаз, бросок, аптечка) поддерживают одновременные нажатия. Расположение, размер и прозрачность настраиваются в «Настройки → Управление → Редактор расположения».

## Что внутри

| Подсистема | Где | Кратко |
|---|---|---|
| Рендер | `src/core/engine.js` | WebGL2, HDR (half-float), GTAO (SSAO), Bloom, ACES + цветокоррекция, хроматическая аберрация, зерно, адаптивное разрешение, обработка потери контекста |
| Материалы | `src/core/materials.js` | PBR-текстуры Poly Haven (albedo/normal/ARM), шейдер-патч: вариация в мировых координатах, лужи и влажные потёки, запечённый AO в вершинах |
| Уровни | `src/world/*` | DSL карт → геометрия с профилями стен (своды станций, арочные тоннели с тюбингами), чанки, PVS-окклюзия, инстансинг пропсов по чанкам, пул источников света, вода |
| Физика | `src/core/physics.js` | Rapier: персонаж (KCC с автоступенькой), динамические предметы (шумят при падении), кинематические двери |
| Игрок | `src/game/player.js` | инерция, бег/выносливость, присед, перелезание, фонарь с cookie-текстурой, тенями, объёмным лучом и пылью |
| Монстры | `src/game/monsters.js`, `creatures.js`, `human.js` | 7 типов: Обращённый, Ползун, Слепой, Охотник, Тень, Королева, Машинист; зрение/слух/реакция на фонарь/двери; процедурная IK-походка |
| Звук | `src/core/audio.js` | полностью процедурный синтез, HRTF, реверберация по зонам, динамическая музыка напряжения |
| Миссии | `src/data/ch1..ch4.js`, `src/game/mission.js` | 32 миссии с уникальными картами, событиями, головоломками, выбором и концовками; контрольные точки |
| Онлайн | `src/net/*` | Supabase: ID игрока, друзья, заявки, приглашения, комнаты с 6-значным кодом; Realtime broadcast/presence для синхронизации |

Проверка карт всех миссий (достижимость точек, ссылки на объекты): `node tools/validate-missions.mjs ch1.js ch2.js ch3.js ch4.js`.

## Онлайн (Supabase)

Схема — таблицы `mh_players`, `mh_friends`, `mh_rooms`, `mh_invites` с включённым RLS без политик (прямой доступ закрыт) и RPC-функции `mh_*` (SECURITY DEFINER), которые проверяют секрет игрока. SQL лежит в `supabase/migrations/`. Ключ в клиенте — публикуемый (publishable), его можно переопределить через `VITE_SUPABASE_URL` / `VITE_SUPABASE_KEY`.

## Ассеты и лицензии

* Текстуры и 3D-модели окружения — [Poly Haven](https://polyhaven.com) (CC0). Скрипт загрузки и оптимизации: `npm run assets` (WebP, meshopt).
* Персонаж — `Soldier.glb` из примеров three.js (риг и анимации Mixamo).
* Монстры (кроме Обращённого/Тени/Машиниста на базе рига) и поезд — процедурная геометрия.
* Все звуки синтезируются в реальном времени (Web Audio API).
