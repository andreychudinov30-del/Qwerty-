# FLY FIGHT — 3D воздушный бой в браузере

Готовая игра — один файл: **`dist/FlyFight.html`** (≈850 КБ, работает офлайн, без сервера). Откройте в Chrome/Safari/Edge на ПК, iPhone или Android (в горизонтальной ориентации).

## Что внутри
- **12 истребителей**: МиГ-29, Су-27, Су-35, Су-57, F-16, F/A-18, F-22, F-35, J-10, J-11, J-16, J-20. Модели строятся процедурно по реальным пропорциям: фюзеляж по сечениям с наплывами и «чайнами», профилированные крылья, отклоняемые элероны/закрылки/стабилизаторы/ПГО/рули, сопла с лепестками и форсажным пламенем, фонарь с кабиной, пилот, приборная панель с МФИ, ракеты на пилонах, шасси (в ангаре), PBR-материалы с разделкой панелей, заклёпками и камуфляжем; LOD для дальних самолётов.
- **Мир**: 7 карт 48×48 км (долина, архипелаг, каньоны, фьорды, мегаполис, высокогорье, вулкан) — рельеф на клипмапе с GPU-смещением, запечённая «спутниковая» текстура (поля, леса, реки, дороги, города, снег, скалы), вода с отражением неба, инстансированные деревья и здания, аэродром, огни города ночью.
- **Атмосфера**: небо с рассеянием, 7 времён суток (рассвет → ночь со звёздами и луной), туман воздушной перспективы, объёмные кучевые облака, перистые облака, дождь, снег, гроза с молниями.
- **Бой 5 на 5**: игрок + 4 ведомых против 5 ботов (преследование с упреждением, уклонение от ракет, ловушки, обход рельефа), пушка с трассерами, ракеты с захватом и пропорциональным наведением, ЛТЦ, ЗРК и зенитки, повреждения (дым, пожар, отказ двигателя), взрывы с частицами, конденсационные следы.
- **10 миссий** с нарастающей сложностью: воздушные бои, удары по кораблям, подавление ПВО, ночной перехват бомбардировщиков, оборона базы, охота на аса, финальное сражение.
- **Меню с 3D-ангаром**: Играть, Миссии, Выбор самолёта, Магазин (самолёты и 8 окрасок), Свободный полёт (карта/время/погода), Настройки, Статистика с контрактами-наградами. Прогресс сохраняется в браузере.
- **Графика**: 5 уровней (Экономный … Ультра), адаптивное разрешение, тени, bloom, MSAA/SMAA.

## Управление
- ПК: W/S — тангаж, A/D — крен, Q/E — рысканье, Shift/Ctrl — тяга (B — форсаж), Пробел/ЛКМ — пушка, F/ПКМ — ракета, X — ловушки, T — цель, C — камера (3-е лицо / кабина), V — назад, M — управление мышью, Esc — пауза.
- Смартфон: плавающий джойстик слева, кнопки ПУШКА/РАКЕТА/ЛТЦ/ЦЕЛЬ/КАМ/ФОРС/ТОРМ справа, ползунок тяги, мультитач; опционально — гироскоп.
- Геймпад: стики, RT — пушка, A — ракета, B — ловушки, Y — камера, RB — цель.

## Сборка
```bash
npm install
npm run build   # -> dist/FlyFight.html
```
Отладка: `dist/FlyFight.html?battle=1&map=alps&time=dawn` — сразу в бой, `?mission=4`, `?free=1`, `&auto=1` — автопилот игрока (демо).
